# Upstream relationship

This is an independent, unofficial plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). It is not maintained or endorsed by DeepSeek.

The plugin uses DSH's documented Client module loader, locale registry, conversation approval slots and active-call projection. It does not vendor or patch the DSH runtime. React is provided by the host application; the development dependency is used only for tests.
